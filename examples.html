Combo: Monte Carlo Pi Estimation

Estimates constant Pi using stochastic random sampling across unit circle.

RNM = ZJIT
use random
use mathX

samples = 1000
inside = 0

loop i from 0 to samples:
  x = random.uniform(-1.0, 1.0)
  y = random.uniform(-1.0, 1.0)
  d = (x * x) + (y * y)
  if d <= 1.0:
    inside = inside + 1
  end
end

pi_est = 4.0 * (inside / samples)
out "=== Monte Carlo Pi Estimator ==="
out "Total Samples :", samples
out "Inside Circle :", inside
out "Estimated Pi  :", pi_est
out "mathX.pi      :", mathX.pi

Combo: Gradient Descent Optimizer

fn cost(x):
  return (x - 4.0) * (x - 4.0)
end

  grad = XCalculus.derivative(cost, x)
  x = x - (lr * grad)

Recursive Quicksort Algorithm

Sorts an array using recursive divide-and-conquer quicksort in ZJIT.

RNM = ZJIT

fn quicksort(arr):
  if len(arr) <= 1:
    return arr
  end
  pivot = arr[0]
  less = []
  greater = []
  loop i from 1 to len(arr) - 1:
    x = arr[i]
    if x <= pivot:
      push x to less
    else:
      push x to greater
    end
  end
  return quicksort(less) + [pivot] + quicksort(greater)
end

data = [42, 12, 88, 3, 27, 91, 15]
out "Unsorted Data:", data
sorted_data = quicksort(data)
out "Sorted Data  :", sorted_data

fn rolling_hash(s):
  h = 0
  p = 31
  m = 1000000009
  p_pow = 1
  loop ch in s:

Combo: Cubic Bezier Curve

Computes points along a smooth cubic Bezier spline for animation paths.

RNM = XITR
use mathX
use Xanmin8

# Control points: P0, P1, P2, P3
p0 = [0.0, 0.0]
p1 = [1.0, 3.0]
p2 = [3.0, 3.0]
p3 = [4.0, 0.0]

fn bezier_point(t):
  u = 1.0 - t
  tt = t * t
  uu = u * u
  uuu = uu * u
  ttt = tt * t
  
  x = (uuu * p0[0]) + (3.0 * uu * t * p1[0]) + (3.0 * u * tt * p2[0]) + (ttt * p3[0])
  y = (uuu * p0[1]) + (3.0 * uu * t * p1[1]) + (3.0 * u * tt * p2[1]) + (ttt * p3[1])
  return [x, y]
end

mid = bezier_point(0.5)
out "=== Cubic Bezier Evaluation ==="
out "Midpoint at t=0.5:", mid
