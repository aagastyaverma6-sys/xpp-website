XPM Package System

Decentralized Package Management

No centralized walled gardens. Install libraries directly from delocalized GitHub repositories with full dependency resolution and lockfiles.

x install github.com/<lib>

Clones or fetches tarball archives directly from GitHub into your project's xpp_packages/ or globally.

git clone & tarball fallbacks

xpp.json & xpp.lock

Deterministic dependency tracking and cryptographic commit pinning so builds reproduce identically everywhere.

x init · x update · x remove

Zero Config In-Code

Import installed packages with natural syntax: use "github.com/owner/repo" or use libname.

works in all 5 RNMs
Batteries Included

34 Standard Libraries Across 4 Domains

Everything from scientific computation and computer algebra to game engines, animated videos, GUIs, and low-level system modules.

Mathematical Libs

mathX (full math & trig), Xsci (Scipy for XPP, quadrature, optimization, FFT), Xnum (Numpy multidimensional NDArray), Xlin (linear algebra, determinants, inverse, eigenvalues), XCAS (Computer Algebra System, differentiation & integration), XCalculus (limits, gradients, divergence, curl, line/surface integrals), Xplotlib (2D, 3D surface, 4D animated plots in GUI/ASCII).

Web Related Libraries

ScrapeX (complete web scraper, DOM parser, CSS selectors, table/link extractors), XWeb (full-stack web pages outputting HTML/CSS/JS, routing, and static export), XWview (embedded webview windows with bidirectional JS bindings).

Development & Creative Libs

GraphiX (2D canvas graphics with CSS styling), XGUI (stunning desktop GUIs with glassmorphism, neo-brutalism, modern dark themes), TerminX (ANSI styling, progress bars, tables, boxes), Xin (keyboard & mouse tracking), GameX (2D/3D games supporting PNG, PSD, TGA, WebP, GIF, SVG, DDS, ASEPRITE and FBX, OBJ, GLTF, BLEND, MAX, MAYA, USD, 3DS, DAE, STL), Xanmin8 (Manim-style mathematical animations).

System & Utility Counterparts

Complete XPP counterparts: os, sys, pathlib, shutil, time, datetime, random, json, csv, re, collections, itertools, functools, urllib, http, socket, unittest, logging, sqlite3.

Engines

All 5 RNMs Supported For Every StdLib

Pick an execution engine with a single header directive — or let x auto-detect it. The language never changes; only the performance backend does.

HeaderEngineDescriptionBackend Architecture
RNM=ZITRNative VM (default)Fast stack VM with NaN-boxing running portable .xbc bytecodeZero-dependency C++17 VM
RNM=ZCOMNative Bytecode AOTCompiles strict pseudocode into verifiable, disassemblable .xbcDeterministic bytecode compiler
RNM=ZJITNative Machine AOTTranspiles directly to C++ and compiles to machine binary (runs fastest)System C++ compiler with VM fallback
RNM=XCOMStrict Python AOTTranspiles strict X++ directly into optimized Python bytecodeCPython compiler
RNM=XITRFast Python VMFast transpilation with cached code objects for scriptingPython runtime
RNM=ITRAI Intent CompilerTranslates loose English descriptions directly into executable programsOpenRouter LLM engine
