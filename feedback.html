Before you write…

My program fails with “X++ [ZITR] error: …” — is that a bug?

Often it's a runtime error your program can handle — wrap the risky part in safe: … fail e: … end and print e. If the message looks wrong or the same code behaves differently on the native VM, please report it — include the smallest snippet that reproduces it.

The playground disagreed with the native VM — what do I include?

The playground is a faithful JS port, but tiny divergences can exist. Send: the exact code, the expected (native) output, and what the playground printed instead. Use the Copy share link button in the playground to get a URL that recreates your exact code.

Can I contribute code to X++?

Yes — pull requests drive the project. The repo (aagastyaverma6-sys/XPP) carries the native C++17 VM, the Python legacy engines, the VS Code extension and the bench suite with 29 golden tests. GPL-3.0-or-later.

Where does my message go?

This form POSTs to a serverless function that emails it to the author's Gmail inbox. Nothing is stored on the website — it's a straight relay. A basic rate limit and a honeypot field keep spam away.
